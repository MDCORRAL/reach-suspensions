# Data Provenance Audit Report

**Repository**: `reach-suspensions`  
**Date**: 2025-11-25  
**Scope**: Raw inputs (`data-raw/`, external locale file), staged Parquet outputs (`data-stage/`), core R pipeline scripts (`R/`, `Analysis/`), Python visualization/dashboard scripts, and documentation references.

## Executive Summary

This audit traces how raw CDE suspension and demographic files (plus an external locale lookup) flow into the staged Parquet datasets used for REACH analyses. The pipeline is primarily driven by the R scripts in `R/` (ingest/feature engineering) and `Analysis/` (teacher merges), with Python scripts consuming the staged Parquet outputs for visuals and dashboards.

Key takeaways:

- **Primary raw sources** are two CDE Excel files (`copy_CDE_suspensions_1718-2324_sc_race.xlsx`, `copy_CDE_suspensions_1718-2324_sc_oth.xlsx`) and CDE staff TXT files (`stre*.txt`).
- **Locale classification** is derived from the `school_locale` column in the race Excel, but the project also uses an **external locale file** (`SchoolSites2425.csv`) outside the repo. This external file must be validated and its upstream merge step documented.
- **Teacher demographics** are ingested separately and merged onto student datasets via `academic_year + cds_school` keys.
- One staged file (`susp_v5_long_strict.parquet`) has an **unknown origin** (not generated by any script found in this audit).

## 3. Variable-Level Provenance (Key Categories)

A full machine-readable table is provided in `outputs/data_audit/data_provenance.csv`. The highlights below cover the primary categories used across analyses and dashboards.

### 3.1 Suspensions, Enrollment, Race/Ethnicity

- **Raw source**: `copy_CDE_suspensions_1718-2324_sc_race.xlsx`
- **Ingest**: `R/01_ingest_v0.R`
- **Key variables**: `total_suspensions`, `cumulative_enrollment`, `reporting_category`, `school_code`, `district_code`, `county_code`, `school_locale`, `grades_served`, `school_type`.
- **Derivations**: Quartiles and race shares computed in `R/03_feature_size_quartiles_TA.R` and `R/04_feature_black_prop_quartiles.R`.

### 3.2 Locale Classification

- **Derived variable**: `locale_simple` in `R/02_feature_locale_simple.R`.
- **Source ambiguity**: The script derives `locale_simple` from `school_locale` already present in the race Excel, but the project also uses an **external file** `SchoolSites2425.csv` (not in repo). If `school_locale` is populated via this external lookup, that merge step must be documented (keys, processing script, and date).

### 3.3 School Level

- **Derived variable**: `school_level` (Elementary/Middle/High/Other/Alternative)
- **Script**: `R/05_feature_school_level.R` uses `grades_served` and `school_type` with helpers in `R/utils_keys_filters.R`.

### 3.4 Suspension Reasons

- **Raw columns**: `suspension_count_violent_incident_injury`, `..._no_injury`, `..._weapons_possession`, `..._illicit_drug_related`, `..._defiance_only`, `..._other_reasons`
- **Script**: `R/06_feature_reason_shares.R`
- **Derived fields**: `prop_susp_*` and long-format `reason` + `prop_of_total_susp`.

### 3.5 Other Demographics (SPED/EL/Foster/etc.)

- **Raw source**: `copy_CDE_suspensions_1718-2324_sc_oth.xlsx`
- **Ingest**: `R/01b_ingest_demographics.R` (uses `R/demographic_labels.R` for recodes)
- **Merge into v6**: `R/22_build_v6_features.R` (left joins by `school_code + academic_year`)

### 3.6 Teacher Demographics

- **Raw source**: CDE Staff Demographics TXT files (`stre*.txt`)
- **Ingest**: `R/01c_ingest_teacher_demographics.R`
- **Summarization**: `R/teacher_processing.R` (`teacher_summarise_long()`)
- **Merge**: `Analysis/22_build_teacher_race_shares.R` (left joins by `academic_year + cds_school`)

## 4. Provenance Gaps and Follow-Ups

1. **External Locale Lookup (SchoolSites2425.csv)**
   - **Gap**: No script in-repo references this CSV directly, yet it is named as the locale classification source.
   - **Follow-up needed**: Identify the preprocessing step that merges this file into the race dataset or generates `school_locale`.

2. **`susp_v5_long_strict.parquet`**
   - **Gap**: File exists in `data-stage/` but no script generating it is found.
   - **Follow-up needed**: Determine origin or remove as untracked artifact. See `docs/audits/AUDIT_REPORT_DATA_CONSISTENCY.md` for prior notes.

3. **Raw File Versioning**
   - **Gap**: Raw data files are not tracked in git, so **first commit** metadata cannot be determined.
   - **Follow-up needed**: Record acquisition dates and checksums (e.g., SHA256) in a future `docs/audits/` addendum.
